# ホスト別アダプター

Agent Plugins 1.0のルートパッケージ（`plugin.json`、`skills/`、`mcp.json`）を正本とする。ホストが別形式を要求する場合だけ、このディレクトリの薄いアダプターを使う。

- `claude/`: Claude Code/Desktopのネイティブ形式。portable Agent Plugins 1.0の自動検出を意味しない。Skillは正本から生成する。
- `openai/`: Codex/ChatGPTの公式サポート面を記録するだけの案内。Codex/ChatGPT用の独自プロバイダーツールや資格情報は含めない。

各ホストのインストール・発見はこのリポジトリではライブ確認していない。確認済みのクリーンプロファイル、クライアントバージョン、日付が記録されるまでは「未検証」と扱う。クローンだけで自動インストールされるとは説明しない。
